# SQL 风控特征工程练习（SQLite）

> 求职简历中「SQL」技能的证据支撑：基于论文数据集（Kaggle「Give Me Some Credit」，15 万条信贷记录）自建的 SQL 特征工程练习，覆盖风控岗位面试高频 SQL 场景。
>
> **定位说明：本目录是求职准备的自建练习/展示项目，不属于任何实习或工作经历；面试表述时请如实说明。** 全部查询零第三方依赖（Python 标准库 `sqlite3` + `csv`）。

## 使用方法

```bash
python sql/run_queries.py
```

流程：建库（`credit.db`，已加入 .gitignore）→ 导入 `data/cs-training.csv` → 顺序执行 `queries.sql` 中的全部查询 → 结果输出到 `sql/results/query_*.csv`（已提交，可直接查看）。

## 查询清单与结果解读

数据说明：`target = SeriousDlqin2yrs`，1 = 未来 90 天以上严重逾期（坏客户）；整体坏账率 **6.68%**（查询 2）。分箱口径与论文（`credit_scoring.py`）保持一致。

| 编号 | 主题 | 面试考点 | 关键结果 |
|---|---|---|---|
| 1 | 缺失率统计 | `COUNT(列)` 跳过 NULL；`AVG(CASE WHEN ...)` 求占比 | 月收入缺失 **19.82%**、抚养人数缺失 2.62%，与论文一致 |
| 2 | 整体坏账率 | 样本结构基准线 | 150,000 条，坏账率 6.68% |
| 3 | 年龄分层坏账率 | `CASE WHEN` 分箱 + `GROUP BY` | 坏账率随年龄单调下降：<25 岁 10.46% → ≥65 岁 2.51%（论文中 age 入选模型的统计依据） |
| 4 | 利用率十分位分箱 | `NTILE` 窗口函数等频分箱 | 坏账率随利用率单调上升：2.52% → **23.17%**（第 10 分位） |
| 5 | **WOE/IV 纯 SQL 计算** | `CTE` + `CROSS JOIN` + `LN` | 90 天逾期次数：WOE 单调递减（0.39 → −3.29），**IV = 0.877**（强预测因子，与论文入选该变量一致） |
| 6 | 逾期行为交叉组合 | 多维 `CASE WHEN` 交叉透视 | 「曾 90 天逾期 + 曾 60-89 逾期」坏账率 55.25%，vs 无逾期行为 3.89% |
| 7 | 逾期总次数特征构造 | 子查询派生字段 + `HAVING` 过滤聚合结果 | 逾期总次数 0 → 2.73%，≥10 次 → 60%+，单调且区分度极高 |
| 8 | 收入五分位坏账率 | `NTILE` 分位分层 | 坏账率 9.05% → 4.50%，有趋势但明显弱于逾期类变量（论文按 IV<0.02 剔除 MonthlyIncome，缺失 19.8% 的填补也会平滑区分度） |
| 9 | 客户收入 vs 同龄人水平 | 先聚合再 `JOIN`（特征工程常用手法） | 示例输出 5 行：id、age、income、同龄平均收入 |
| 10 | 策略规则模拟 | 策略规则翻译成 `WHERE` 条件；命中率评估规则可用性 | 规则「利用率 ≥0.9 且 30-59 逾期 ≥2 次」命中 2,816 人（命中率 1.88%），坏账率 **47.51%**（约为整体的 7 倍） |

## 面试怎么用

- 被问「用过 SQL 吗」：直接说「在信用评分项目里用 SQLite 做过一轮风控特征工程练习，仓库里有 10 个查询和结果」，并引导对方看仓库 `sql/` 目录；
- 被问「SQL 做过什么」：重点讲查询 5（WOE/IV 纯 SQL 实现）和查询 10（策略规则模拟），这两个最能体现「SQL 服务于风控业务」；
- 被问「收入为什么不进模型」：查询 8 的结果 + 论文 IV 阈值论证是一条完整的故事线；
- 诚实边界：这是公开数据集上的练习，不是生产环境/工作经历。
